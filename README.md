The Unit Converter is a Python-based application that allows users to convert units of distance and temperature. It supports conversions between kilometres and miles, as well as Celsius and Fahrenheit. The program uses a menu-driven interface to accept user input, perform calculations using predefined conversion functions, and display the results rounded to two decimal places. It also includes an exit option and input validation for menu choices. This project demonstrates the use of Python functions, modules, conditional statements, loops, and user input handling.
